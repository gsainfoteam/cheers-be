# public.notification_log

## Description

이메일 · 카카오 알림톡 전송 로그 (channel로 구분). 시도마다 새 행. 실패한 행에 next_retry_at이 있으면 재시도 스케줄러가 처리하고 비움 (CRB-75). 접수된 알림톡은 결과 동기화 스케줄러가 알리고에서 카카오 최종 결과를 가져와 delivery_*에 남김 (CRB-77)
